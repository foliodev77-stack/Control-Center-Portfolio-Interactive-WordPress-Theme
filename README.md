# Control Center Portfolio – Interactive WordPress Theme

A futuristic iOS-inspired WordPress portfolio theme featuring glassmorphism UI, smooth animations, custom cursor, brightness and volume controls, background music/video, project showcase, responsive design, and interactive Control Center-style panels.

## Features

- iOS Control Center-inspired glassmorphism interface
- Responsive portfolio layout
- Interactive brightness and volume controls
- Background media player and animated equalizer
- Smooth reveal and hover animations
- Custom cursor effects
- Services and project showcase sections
- Fictional ALEX demo profile
- Generic demo projects and placeholder contact details
- WordPress-ready theme structure

## Installation

1. Download or clone this repository.
2. Put the files in a folder named `control-center-portfolio-demo`.
3. Copy it to `wp-content/themes/`, or ZIP the folder and upload it from **WordPress → Appearance → Themes → Add New → Upload Theme**.
4. Activate **Control Center Portfolio Demo**.
